# LDAR Calendar

Sketch of one person, one calendar: invite, group defaults, subscription. Not a product decision.

## Try it in the browser

**https://phena109.github.io/ldar-calendar/**

Single static page. No local files. Switch **Janice / 阿啟 / 媽媽 / 美姨 / Sam** (not a login). Janice layout is cute; 阿啟 is Outlook-like. Week / month / year. HK 2026 gazetted general holidays marked. State is in the browser (`localStorage`); **Clear & reset** restores the seed. **Demo notes** lists what this sketch will not pretend to do.

EN / 香港繁體中文.
