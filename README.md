# LDAR Calendar

Sketch of one person, one calendar. Groups as shared layers. Extra invite only for people outside the group. Not a product decision.

## Try it in the browser

**https://phena109.github.io/ldar-calendar/**

Single static page. Switch **Janice / 阿啟 / 媽媽 / 美姨 / Sam** (not a login). Janice layout is cute; 阿啟 is Outlook-like.

Try: as Janice, put an activity on the **Partner layer**, then switch to 阿啟 — it is already on his week, no pending invite. Turn a layer off or tap **×** = hide on that person’s side only.

Week / month / year. HK 2026 gazetted general holidays marked. State is in the browser (`localStorage`); **Clear & reset** restores the seed. **Demo notes** lists what this sketch will not pretend to do.
